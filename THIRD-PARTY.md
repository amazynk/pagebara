## ICC colour profiles

PDF/A output intents and default colour spaces use ICC profiles that Pagebara generates
itself (`crates/conform/src/icc.rs`): an sRGB profile computed from the published
IEC 61966-2-1 primaries, white point and tone curve, and a CMYK profile that models the
plain CMYK-to-RGB conversion. No third-party profile file is included, so there is no
licence to follow beyond Pagebara's own.

## OCR models

Text recognition uses the PP-OCRv5 models by PaddlePaddle
(https://github.com/PaddlePaddle/PaddleOCR, https://huggingface.co/PaddlePaddle),
Copyright (c) PaddlePaddle Authors, licensed under the Apache License, Version 2.0
(https://www.apache.org/licenses/LICENSE-2.0). The models are not in the source tree.
Release builds (the Linux packages and the Android APK) carry the text detection and Latin
recognition models inside the program, so text in pictures is read offline
(`packaging/ocr-bundle.sh` fetches the pinned files and checks their SHA-256 at build
time). The other scripts' models and the orientation classifiers are downloaded, from
pinned revisions, only when the user asks for text recognition, and each file's SHA-256
is checked (`pagebara_ocr::model`). They run with RTen
(https://github.com/robertknight/rten, MIT OR Apache-2.0). The About page in Settings and
the text recognition dialog show this attribution (`pagebara_ocr::model::ATTRIBUTION`).

## Hyphenation patterns

`pagebara-typeset` hyphenates US English with the hyphenation patterns of plain TeX by Donald E.
Knuth and Frank M. Liang (`hyphen.tex`, from CTAN, `macros/plain/base/hyphen.tex`), compiled
into the program from `crates/typeset/data/hyphen-en-us.tex`. The file is the original,
unmodified; only its name differs. Its terms: "Unlimited copying and redistribution of this
file are permitted as long as this file is not modified. Modifications are permitted, but
only if the resulting file is not named hyphen.tex." These are permissive, free terms
compatible with distributing Pagebara under MIT OR Apache-2.0.

British English, German, French, Spanish, Italian, Portuguese, Dutch, Polish and Ukrainian
use the hyph-utf8 patterns (https://github.com/hyphenation/tex-hyphen), unmodified, in
`crates/typeset/data/hyph`, compressed into the program. They are under the MIT licence
(Italian, Polish and Ukrainian are offered under a choice of licences that includes MIT,
which Pagebara uses) except Portuguese, which is under the BSD 3-clause licence. Their
copyright notices and licence texts are in `crates/typeset/LICENSE-hyphenation`, installed
as `LICENSE-hyphenation`. Russian and Turkish patterns are available only under the LPPL,
so Pagebara does not include them.
